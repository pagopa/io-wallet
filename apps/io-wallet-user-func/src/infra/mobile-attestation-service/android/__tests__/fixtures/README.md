# Test fixtures

Do not reformat these files, otherwise the signatures become invalid.

- `allowed_signers`, `attestation*.json` and `attestation*.json.sig` are signed with a throwaway test key by
  `ssh-keygen -Y sign -n "attestation keys"`, whose private key has been discarded.
- `grapheneos-allowed_signers`, `grapheneos-attestation.json` and `grapheneos-attestation.json.sig` are the real files
  published by GrapheneOS, copied from https://github.com/GrapheneOS/grapheneos.org/tree/main/static.
- `grapheneos-pixel9-auditor/` is a real key attestation chain generated by the GrapheneOS Auditor app on a Pixel 9
  running GrapheneOS 2025110600, with an app attest key, and the Google root which signs it, copied from
  https://github.com/GrapheneOS/Auditor/tree/main/samples/5, Copyright © 2018-2025 GrapheneOS, MIT license.
